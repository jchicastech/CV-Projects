# CV-Projects

A collection of Computer Vision (CV) projects implemented as Jupyter notebooks. This repository explores various CV techniques and algorithms using Python and popular libraries such as OpenCV, scikit-image, and deep learning frameworks.

## Projects

| Notebook | Description |
|----------|-------------|
| [notebooks/image_processing_basics.ipynb](notebooks/image_processing_basics.ipynb) | Fundamental image processing operations: loading, displaying, color spaces, filtering, and edge detection |

## Getting Started

### Prerequisites

- Python 3.8+
- Jupyter Notebook or JupyterLab

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/jchicastech/CV-Projects.git
   cd CV-Projects
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Launch Jupyter:
   ```bash
   jupyter notebook
   ```

## Dependencies

Core libraries used across notebooks:

- **OpenCV** (`opencv-python`) – image reading, processing, and computer vision algorithms
- **NumPy** – numerical operations on image arrays
- **Matplotlib** – visualization and plotting
- **scikit-image** – additional image processing utilities
- **Pillow** – image I/O and basic manipulation

See [requirements.txt](requirements.txt) for the full list with pinned versions.
